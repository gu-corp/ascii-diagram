# ASCII Diagram Demo

## Simple Box

```ascii
┌─────────────┐
│   Hello!    │
└─────────────┘
```

## Japanese Text

```ascii
┌─────────────┐
│  日本語     │
└─────────────┘
```

## Flow Diagram

```ascii
┌─────────────┐     ┌─────────────┐
│   ユーザー   │────▶│   Exchange  │
└─────────────┘     └─────────────┘
```

## Vertical Flow

```ascii
┌─────────┐
│ステップ1│
└────┬────┘
     │
     ▼
┌─────────┐
│ステップ2│
└────┬────┘
     │
     ▼
┌─────────┐
│ステップ3│
└─────────┘
```

## Nested Boxes

```ascii
┌─────────────────────────────┐
│  外側のボックス             │
│  ┌───────────────────┐      │
│  │  内側のボックス   │      │
│  └───────────────────┘      │
└─────────────────────────────┘
```

## Table-like Structure

```ascii
┌──────┬──────┬──────┐
│  A   │  B   │  C   │
├──────┼──────┼──────┤
│  1   │  2   │  3   │
├──────┼──────┼──────┤
│  4   │  5   │  6   │
└──────┴──────┴──────┘
```

## Arrow Types

```ascii
───▶  横方向右
◀───  横方向左
  │
  ▼   縦方向下
  │
  ▲   縦方向上
```
